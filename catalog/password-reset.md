# Password Reset Service

## Description
Allows users to reset or recover their account passwords.

## Customer Value
- Quick restoration of access
- Minimizes downtime

## Workflow
1. User submits request or uses self-service
2. Identity verification
3. Password reset
4. Confirmation

## SLA
- Immediate to 15 minutes

## OLA
- Identity verification within minutes

## Automation Opportunities
- Self-service portal
- Multi-factor authentication
- Automated reset tools
