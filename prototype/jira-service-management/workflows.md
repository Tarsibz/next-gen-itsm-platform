# Jira Service Management Prototype

## Platform Used
Jira Service Management

## Goal
This prototype demonstrates how the NexaITSM platform design can be implemented in Jira Service Management.

## Implemented Features
- Service catalog with 10 request types
- Grouped service categories
- Incident management workflow
- Request workflow with approval
- Knowledge base articles
- Basic ticket lifecycle
- Sample demo tickets

## Request Type Groups
- Hardware & Infrastructure
- Access & Security
- Software & Applications
- Support & Incidents
- Communication Services
- Onboarding Services

## Detailed Request Types

The most detailed configurations were created for the following services to demonstrate advanced ITSM workflows:

- Laptop Provisioning (approval workflow)
- Access Management (controlled access with approval)
- New Employee Onboarding (multi-step fulfillment process)
- Incident Reporting (priority-based incident handling)

## Standard Request Types

The remaining services were implemented with simplified configurations to demonstrate completeness of the service catalog:

- Password Reset
- Software Request
- Data Recovery
- Server Provisioning
- VPN Access
- Distribution List Request

While these services may require approvals in real-world scenarios, simplified configurations were used in the prototype to maintain focus on key workflows.
