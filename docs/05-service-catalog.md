# 5. Service Catalog Design

## 5.1 Overview

The NexaITSM platform includes a centralized service catalog that provides users with a structured and user-friendly interface to request IT services.

The service catalog is designed to:
- Simplify user interaction with IT
- Standardize service delivery
- Enable automation
- Improve response and fulfillment times

---

## 5.2 Service Catalog Principles

The catalog is designed based on the following principles:

- Customer-centric design
- Clear service descriptions
- Standardized workflows
- Defined SLAs and OLAs
- Automation-first approach
- Self-service capability

---

## 5.3 List of Services

The platform includes the following core services:

1. Laptop Provisioning  
2. Password Reset  
3. New Software Request  
4. Incident Reporting  
5. Data Recovery Request  
6. Server Provisioning  
7. Access Management  
8. VPN Access Request  
9. Distribution List / Shared Mailbox Request  
10. New Employee Onboarding IT Setup  

---

## 5.4 Service Structure

Each service in the catalog includes:

- Description
- Customer value
- Workflow
- SLA (Service Level Agreement)
- OLA (Operational Level Agreement)
- Automation opportunities

---

## 5.5 Summary

The service catalog acts as the primary interface between users and IT. By standardizing and automating service delivery, it significantly improves efficiency, transparency, and user satisfaction.
